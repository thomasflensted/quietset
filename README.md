# Quietset

Quiet home workouts: 5 exercises, 5 rounds. Static HTML, CSS and JS with no build step and no dependencies.

- `exercises.js`: the exercise library (add or remove exercises here)
- `app.js`: generation, history (last 5 in localStorage), rendering
- `style.css`: styles, light and dark mode

## Run locally

Open `index.html` in a browser, or run `npx serve .`.

## Hosting

Hosted on GitHub Pages from the `main` branch: https://thomasflensted.github.io/quietset/

Push to `main` and the site updates within a minute.
